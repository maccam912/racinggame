# Forest places

Nine courses now have wider, individually named grove parcels: Palm Bay, Citrus Pass, Redwood Run, Alpine Meadow, Rainforest Ruins, Cloudforest Climb, Sakura Ring, Bamboo Gorge and Temple Coast. Mixed species, asymmetric setbacks and varying tree scales build foreground, middle ground and distant cover while preserving beach, meadow, shrine and orchard openings. Selected tall forest and understory parcels have explicit size ranges. Placement still checks every road branch and poster reservation and uses spatially culled batches.

The nine native course photographs and shipped 512×288 thumbnails were refreshed. Four further driving-height views per course, capture source and source hashes are included. These are real macOS scene renders.

The complete source gate passed all 209 commands; see checks.json. Gameplay content and frozen terrain exports are unchanged. An isolated production-client before/after run covered Redwood Run and Rainforest Ruins with eight cars at Medium, 1920×1080 and a 60 fps cap. Both runs finished both races with all eight cars and recorded 8,847 frames. Frame p95 changed from 17.678 to 17.882 ms, p99 from 18.739 to 18.740 ms; each run had one frame above 33 ms. The retained performance reports omit only the large per-frame spatial arrays.

This evidence establishes local source behavior and the recorded macOS views and timings. It does not establish physical Android performance, exported-build behavior or human driving acceptance.
