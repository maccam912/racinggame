# Visible setup feedback and paint shortcut

Relaxed setup displays the existing turquoise selection style and a checkmark
while its race and assist settings match. Changing laps, rivals, difficulty,
contact or course updates that state; selecting a technical course removes it.
It does not claim the preset is active merely because it was pressed earlier.

The garage footer provides a Paint choice with the current swatch. Desktop uses
the normal choice popup; touch uses the existing scrollable choice sheet. The
full named paint palette remains available below the car cards. Choosing any of
the eight paints preserves the car and returns focus to the visible shortcut.

Five focused source, assist/settings, garage interaction, 90-layout and 36-filter
checks pass. Native desktop and 884x398 phone captures at 150% text were reviewed:
[paint on desktop](paint-desktop.png), [paint on phone](paint-phone150.png),
[active Relaxed setup](relaxed-phone150.png). No physics or default settings changed.
