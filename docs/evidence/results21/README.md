# Readable race results

Race rows now show a prominent finishing place, the actual car silhouette, racer
name and explicitly labelled total time, gap and best clean lap. The local racer
retains the highlighted panel and automatic reveal. Unfinished races retain DNF
and their reason; save failures retain Retry priority. No records or rank rules
change.

Native phone/tablet/desktop checks cover 100/125/150% text size, first/last place,
long grapheme names and DNF. All local cards fit inside their scroll viewport.
Keyboard/controller focus remains on actions; save failure stays at the Retry
control. Integral highlight padding avoids fractional bottom-border clipping.
Five focused commands pass for source, result receipts, retry, result layouts and
touch scrolling. Native phone captures at 100% and 150% were visually reviewed.
