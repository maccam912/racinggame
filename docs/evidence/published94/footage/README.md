# Published Build 94 driving footage

[Palm Bay](palm-bay.mp4) shows the first fast coastal approach, climb and drop.
[Summit](summit-flight.mp4) shows the crest structures, flight and descent.
Both run the exact downloaded macOS package from
[v0.0.94-dev](https://github.com/maccam912/racinggame/releases/tag/v0.0.94-dev),
with normal HUD, seven opponents and ordinary diagnostic AI inputs.
They include the painted posters, foliage and detailed rock checkpoint.

These are fixed 60 Hz / 60 fps Movie Maker recordings, preserving normal game
pace. They do not measure live frame timing, another operating system or human
driving feel. Only time ranges and H.264/AAC encoding changed; no scenery, camera,
vehicle or HUD was composited. The [manifest](manifest.json) retains raw movie and
encoded hashes, exact frame counts, trim ranges and embedded build sidecars.

Use the reproduction command from the [earlier footage notes](../../content5/footage/README.md)
with the published Build 94 executable and fresh diagnostic profiles. The exact
new Palm cut starts at 7.5 seconds for 28.25 seconds; Summit starts at 46 seconds
for 14 seconds. Inspected source frames show Summit's racing clock at 40, 44 and
48 seconds at source-movie times 46, 50 and 54 seconds. Raw AVIs stay outside Git.
