# Forty-course roster

Owner request, 21 October 2026: expand the game to forty courses, with varied
settings, route shapes and driving experiences. Retain the ten existing routes.
Every addition below needs its own authored control polygon, not a recolored
copy. The table is the implementation brief; it is not a completion claim.

## Build and acceptance sequence

1. Correct defaults and tire audio. Source human-authored CC0 heavy rock/metal,
   retain original files, source URLs, license evidence and reversible mix scripts.
2. Reproduce Summit's localized stalls with native rendering and route-position
   timing. Preserve collision, visibility and recognizable balloon scenery.
3. Author all thirty routes in canonical JSON and bake with the existing tool.
   Reject sub-28 m corners, excessive grades, bad crossings and invalid starts.
4. Generate reusable original illustrated scenery atlases using the imagegen
   skill: polar/alpine, tropical, East Asian, desert/plains, industrial/festival,
   and space/crystal. Preserve source pixels and prompts; use alpha-bounded atlas
   cells. Add inexpensive actual 3D landmark structures and themed terrain.
5. Connect every course to selection, names/descriptions, maps/postcards, audio,
   server validation, records and rendering. Keep Coast Cup's established event
   sequence unless explicitly redesigned; all forty are available in other modes.
6. Preserve the current content-11 archive before advancing gameplay content.
   New content invalidates comparison/continuation but retains old records,
   ghosts, Cups and saved races as archives. Do not edit older frozen fixtures.
7. Validate all forty route geometries, standing-start AI races, camera clearance,
   course identity and native representative views. Verify new audio loop/mix
   boundaries and run the comprehensive source gate. Report source checks,
   rendered-host evidence and exported/physical-device evidence separately.

Progress is recorded in `docs/STATUS.md`. Weekly usage was 73% remaining at
the first check; stop at 30% or less remaining without resuming autonomously.
